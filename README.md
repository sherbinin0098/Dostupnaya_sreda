# Горыныч: проверка доступности

Android-приложение проекта «Мастерская Горыныча: Экспертиза на колёсах» (Новосибирск).

Вводите замер на объекте и сразу получаете результат по нормам: соответствует, не соответствует, допустимо при условии (приложение показывает условие, вы его проверяете), ниже современной нормы (здание до 01.07.2016) или нет нормы в справке. Есть журнал с фото, калькулятор уклона пандуса, экспорт CSV, текст для акта и обращения. Работает без интернета.

Нормы: справка на 24.10.2026 — СП 59.13330.2020 (изм. 1–4), СП 140.13330.2024, СП 136.13330.2012, ГОСТ Р 51261-2025, ГОСТ 33652-2019. Значения со статусом «Требует сверки» нужно проверить по полному тексту. Результат — рабочая подсказка, а не юридическое заключение.

## Что умеет

- **Замер → сразу результат по норме** с номером пункта: соответствует, не соответствует, допустимо при условии, ниже современной нормы (здание до 01.07.2016), нет нормы.
- **«Тройственный взгляд»** в каждом замере: факт и норма, опыт эксперта («как это на коляске») и что реально сделать (с подсказками типовых решений).
- **Подтверждающие фото** — три окошка: общий вид, замер рулеткой, деталь. На снимок можно ставить подпись: дата, место, координаты.
- **Место на карте**: умный поиск по названию и адресу (подсказки рядом с вами), «Я здесь» по GPS, выбор точки на карте; все замеры на карте цветом результата.
- **Экспорт**: отчёт с фото (страница, открывается везде, печатается в PDF), таблица CSV, текст для акта и обращения.
- **Доступ — можно ли вообще добраться**: сколько входов доступно без ступеней и сколько ступеней без пандуса до входа; есть ли места для инвалидов на стоянке и препятствия (бордюр без съезда) до тротуара; переходы без съезда; раздел «Доступ к помещениям»: сколько ступеней без пандуса и этажей без лифта на пути к туалету, к зоне услуг и к любому другому помещению, и сколько помещений закрыто или недоступно. Работает голосом («туалет ступени — три», «нет» = ноль), попадает в журнал, письмо, паспорт и публичную карту; на экране «Замер» показывается предупреждение, что помещение недоступно, даже если его размеры в норме.
- **Резервная копия** — один файл со всеми данными и фото, переносится на новый телефон.
- **Маршрут обследования**: для здания или улицы приложение ведёт по пунктам по порядку, показывает «проверено 12 из 45» и подсказывает следующий; пункты, которых нет на объекте, можно пропустить.
- **Голосовой ввод числа** кнопкой с микрофоном: «девяносто пять сантиметров» превращается в 950 мм, «метр двадцать» — в 1200 мм; для расстояний число понимается в метрах. Понятое число показывается для проверки.
- **Диктовка (телефон лежит, руки заняты рулеткой)**: на экране крупно кодовая фраза следующего замера («дверь ширина»), она же озвучивается (озвучку можно выключить). Сразу после фразы телефон слушает число, записывает, повторяет его вслух и называет следующую фразу. Ничего не спрашивает и ничего нажимать не нужно: голосовые команды «отмена», «пропустить», «нет такого», «повтори», «пауза». Необычное число записывается с пометкой «проверьте» в журнале, а вслух приложение предупреждает. Когда блок соседних замеров (раздел) закончился, диктовка останавливается: «Блок … закончен, следующий блок …»; телефон слушает только слово «дальше» (или кнопка «Дальше»). Тишина — телефон продолжает слушать; экран не гаснет.
- **Голос списком**: кнопка в маршруте открывает экран с ключевыми фразами для каждого пункта («дверь ширина», «порог высота»…). Говорите фразу и число подряд, приложение раскладывает по пунктам и показывает, как поняло; перед сохранением числа можно поправить.
- **Уклономер**: телефон на пандусе показывает продольный и поперечный уклон в промилле и сверяет с нормой (с калибровкой; точность около ±5‰, у границы нормы проверяйте рулеткой).
- **До и после**: повторное обследование того же объекта показывает, что устранено, что нет и что ухудшилось. Отчёт и текст для обращения.
- **Обращения со сроками**: кому и когда отправили, срок ответа (по умолчанию 30 дней), напоминание на экране замера, файл для календаря, ответ и итог.
- **Сводка**: графики по результатам, разделам и объектам, за любой период.
- **Паспорт доступности ОСИ**: титульный лист, обозначения, паспорт по структуре приложения А.2 приказа Минтруда № 627 (разделы 1–5, коды ДП-И, ДЧ-И, ДУ, ВНД, рекомендации по зонам), приложения с замерами и нумерованной фотофиксацией. Поля можно править на странице перед печатью. Коды предварительные, их утверждает комиссия.
- **Справка о результатах обследования** — краткая версия с нарушениями и фото.
- **Публичная карта доступности** (папка `docs/`): страница на GitHub Pages с картой, фильтрами и карточками объектов. Данные берутся из файла, который создаёт приложение (Ещё → Экспорт → «Данные для публичной карты»; без фото и заметок).
- **Парковка для инвалидов**: нормы по размерам и расстоянию (СП 59, п. 5.2) и расчёт, сколько мест нужно на стоянке.
- **Защита от опечаток**: если число выглядит нереально (например 9500 мм вместо 950), приложение спросит и предложит исправление.
- **Крупный режим** (Ещё → «Размер кнопок и текста»): увеличенные шрифты и кнопки.
- **Правка фото**: стрелки и подписи на снимке прямо в приложении.
- **Объединение с файлом коллеги**: «Добавить из файла» подтягивает чужие объекты и замеры, ваши данные не меняются.
- **Письмо-обращение** одной кнопкой, **акт обследования** и **анкета** (Экспорт).
- **Напоминания о сроках ответа** (уведомления в 09:00 накануне и в день срока); на экране «Замер» — напоминание сделать резервную копию, если её не было 14 дней.
- **Простой режим** (Ещё): без выбора разделов, сразу следующий пункт маршрута; незаконченный замер не пропадает при закрытии приложения. Памятка для печати — `docs/pamyatka.html`.
- Калькулятор уклона пандуса по табл. 5.1 СП 59.

Без интернета работает всё, кроме карты и поиска адреса. Политика конфиденциальности — [PRIVACY.md](PRIVACY.md).

## Как установить на телефон

1. Откройте на телефоне раздел [Releases](../../releases) и скачайте `gorynych-dostupnost.apk` из самой новой сборки.
2. Откройте файл. Android попросит разрешить установку из этого источника: нажмите «Настройки», включите разрешение, вернитесь и нажмите «Установить».
3. Если Play Защита предупредит, нажмите «Подробнее» → «Всё равно установить».

Новые версии ставятся поверх старой, данные на телефоне сохраняются. Для этого все версии подписаны одним и тем же ключом.

## Как выпустить обновление

Любое изменение в ветке `main` запускает сборку (вкладка Actions). Через 5–10 минут в Releases появится новая сборка с файлами:

- `gorynych-dostupnost.apk` — для установки из файла;
- `gorynych-dostupnost-google-play.aab` — для загрузки в Google Play (когда понадобится).

Нормы лежат в `src/data/rules.json`; дата справки в `NORMS_VERSION` (`src/core/rules.ts`). Устройство кода, команды и проверки — в [DEVELOPING.md](DEVELOPING.md).

Иконка: исходник `icon.png`, готовые картинки для Android лежат в `android-res/`. Если меняете иконку — замените `icon.png` и выполните `bash tools/make-icons.sh` (нужен ImageMagick).

Пробную сборку с другой ветки можно запустить вручную (Actions → «Сборка APK» → Run workflow): она попадёт только в Artifacts, в Releases — нет.

## Ключи подписи (секреты GitHub)

Ключи в репозитории не хранятся. Они лежат в Settings → Secrets and variables → Actions:

| Секрет | Что это |
|---|---|
| `SIDELOAD_KEYSTORE`, `SIDELOAD_PASSWORD` | ключ для установки из файла (APK) |
| `UPLOAD_KEYSTORE`, `UPLOAD_PASSWORD` | ключ загрузки в Google Play (AAB) |

`*_KEYSTORE` — файл ключа, закодированный в base64 одной строкой (`base64 -w0 файл.jks`); псевдонимы ключей `sideload` и `upload`, пароль ключа совпадает с паролем хранилища.

**Храните копию ключей и паролей отдельно** (менеджер паролей, флешка): из секретов GitHub их обратно не прочитать. Потерян ключ `SIDELOAD_*` — новые версии не встанут поверх старых, приложение придётся удалить и поставить заново (данные журнала пропадут, сначала сделайте резервную копию: Ещё → Экспорт → «Резервная копия»). Если секретов нет, сборка останавливается с понятным сообщением; сборка проверяет, что APK подписан именно ключом из секрета.

## Публичная карта: как включить

1. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`. Адрес будет `https://sherbinin0098.github.io/Dostupnaya_sreda/`.
2. Каждый из участников в приложении создаёт файл «Данные для публичной карты» и отправляет его.
3. На странице карты можно выбрать несколько файлов сразу, они объединятся; кнопка «Скачать объединённый data.json».
4. Загрузите `data.json` в папку `docs/` репозитория (Add file → Upload files). Страница покажет все объекты.

## Google Play и Capacitor 8
Пробная сборка с Capacitor 8 (нужна Google Play, Android 7+): Actions → «Сборка APK» → Run workflow → capacitor = 8. Результат лежит в Artifacts и в Releases не публикуется.
