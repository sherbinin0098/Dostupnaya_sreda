# Горыныч: проверка доступности

Android-приложение проекта «Мастерская Горыныча: Экспертиза на колёсах» (Новосибирск).

Вводите замер на объекте и сразу получаете результат по нормам: соответствует, не соответствует, допустимо при условии (приложение показывает условие, вы его проверяете), ниже современной нормы (здание до 01.07.2016) или нет нормы в справке. Есть журнал с фото, калькулятор уклона пандуса, экспорт CSV, текст для акта и обращения.

Нормы: справка на 23.10.2026 — СП 59.13330.2020 (изм. 1–4), СП 140.13330.2024, ГОСТ Р 51261-2022. Значения со статусом «Требует сверки» нужно проверить по полному тексту. Результат — рабочая подсказка, а не юридическое заключение.

## Как получить APK

Любое изменение в ветке main запускает сборку (вкладка Actions). Через 5–10 минут в Releases появится `gorynych-dostupnost.apk`. Скачайте и установите.

Нормы лежат в `index.html` в массиве `RULES`.
