# Горыныч: проверка доступности

Android-приложение проекта «Мастерская Горыныча: Экспертиза на колёсах» (Новосибирск).

Вводите замер на объекте и сразу получаете результат по нормам: соответствует, не соответствует, допустимо при условии (приложение показывает условие, вы его проверяете), ниже современной нормы (здание до 01.07.2016) или нет нормы в справке. Есть журнал с фото, калькулятор уклона пандуса, экспорт CSV, текст для акта и обращения. Работает без интернета.

Нормы: справка на 23.10.2026 — СП 59.13330.2020 (изм. 1–4), СП 140.13330.2024, ГОСТ Р 51261-2022. Значения со статусом «Требует сверки» нужно проверить по полному тексту. Результат — рабочая подсказка, а не юридическое заключение.

## Как установить на телефон

1. Откройте на телефоне раздел [Releases](../../releases) и скачайте `gorynych-dostupnost.apk` из самой новой сборки.
2. Откройте файл. Android попросит разрешить установку из этого источника: нажмите «Настройки», включите разрешение, вернитесь и нажмите «Установить».
3. Если Play Защита предупредит, нажмите «Подробнее» → «Всё равно установить».

Новые версии ставятся поверх старой, данные на телефоне сохраняются. Для этого все версии подписаны одним и тем же ключом.

## Как выпустить обновление

Любое изменение в ветке `main` запускает сборку (вкладка Actions). Через 5–10 минут в Releases появится новая сборка с файлами:

- `gorynych-dostupnost.apk` — для установки из файла;
- `gorynych-dostupnost-google-play.aab` — для загрузки в Google Play (когда понадобится).

Нормы лежат в `index.html` в массиве `RULES`; дата справки в `NORMS_VERSION`.

## Ключи подписи (секреты GitHub)

Ключи в репозитории не хранятся. Они лежат в Settings → Secrets and variables → Actions:

| Секрет | Что это |
|---|---|
| `SIDELOAD_KEYSTORE`, `SIDELOAD_PASSWORD` | ключ для установки из файла (APK) |
| `UPLOAD_KEYSTORE`, `UPLOAD_PASSWORD` | ключ загрузки в Google Play (AAB) |

`*_KEYSTORE` — файл ключа, закодированный в base64 одной строкой (`base64 -w0 файл.jks`); псевдонимы ключей `sideload` и `upload`, пароль ключа совпадает с паролем хранилища.

**Храните копию ключей и паролей отдельно** (менеджер паролей, флешка): из секретов GitHub их обратно не прочитать. Потерян ключ `SIDELOAD_*` — новые версии не встанут поверх старых, приложение придётся удалить и поставить заново (данные журнала пропадут, сначала сделайте резервную копию на вкладке «Экспорт»). Если секретов нет, сборка останавливается с понятным сообщением; сборка проверяет, что APK подписан именно ключом из секрета.
