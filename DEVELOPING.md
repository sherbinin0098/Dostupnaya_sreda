# Для разработчика

Приложение — веб-часть на TypeScript (сборка Vite в один файл `index.html`), которая упаковывается в Android-приложение через Capacitor. Голос без системного окна — небольшой плагин на Java (`android-src/`).

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | ставит зависимости |
| `npm run dev` | локальный сервер для разработки |
| `npm run typecheck` | проверка типов (`tsc`) |
| `npm test` | модульные тесты (vitest): справка норм, проверка замеров, голос, перевод старых данных, парковка |
| `npm run build` | рабочая сборка в `dist/index.html` |
| `npm run e2e` | сквозные тесты в настоящем браузере (нужен Chromium: `npx playwright install chromium`) |
| `npm run format` | приводит код к единому виду (prettier) |

Те же проверки (типы, тесты, сквозные тесты) запускает GitHub Actions на каждой ветке: `.github/workflows/check.yml`. Сборка APK: `.github/workflows/build-apk.yml` (только из `main`).

## Устройство

```
src/
  data/rules.json        справка норм (код правила, раздел, мин/макс, пункт, документ, статус, условие)
  data/phrases.json      кодовые фразы для голоса и то, что приложение произносит вслух
  core/                  логика без экранов: types, rules (проверка по норме), storage (localStorage, перевод единиц),
                         util, calc (парковка, наклон), voice-parse (число и фраза голосом), state, draft
  screens/               экраны: measure, log, export, norms, appeals, stats, tools, voice-list, dictation
  reports/               отчёты и документы: basic (CSV, текст), report, compare, passport, passport-short, letter, public
  ui/common.ts           каркас: вкладки, render(), общие блоки
  place.ts photos.ts     место (GPS, карта, поиск адреса) и фото (подпись, пометки)
  native.ts voice.ts     Android: Capacitor-плагины, голос
  route.ts tilt.ts ...   маршрут обследования, уклономер, напоминания, резервная копия
  main.ts                точка входа
tests/                   модульные тесты (vitest) и tests/e2e (сквозные)
android-src/             Java-плагин голоса (подставляется при сборке APK)
docs/                    публичная карта (GitHub Pages), политика конфиденциальности, памятка
```

Экранный код написан в стиле «найти элемент и повесить обработчик», поэтому типы DOM-элементов в нём ослаблены (`src/globals.d.ts`). Данные, нормы и логика проверок типизированы строго (`src/core/types.ts`).

## Как внести новую норму

1. Добавьте запись в конец `src/data/rules.json`: следующий код `R…`, раздел (`group`), название, единица (`мм`, `м`, `‰`, `%`, `лк`, `с`, `Нм`, `шт`), `min`/`max`, пункт (`clause`) и документ (`doc`). Если не уверены в числе — `"status": "chk"` (требует сверки) или `"empty"` без чисел; выдумывать нельзя.
2. Если норма смягчается при реконструкции — `amin`/`amax` и текст условия в `cond`.
3. Добавьте кодовую фразу для голоса в `src/data/phrases.json` (`phrases`); для счётчиков можно добавить вопрос в `say`.
4. Обновите `NORMS_VERSION` в `src/core/rules.ts`.
5. `npm test`: тесты проверят уникальность кодов, согласованность границ, наличие фразы, что фразы не вложены друг в друга, что раздел входит в маршрут и в зоны паспорта.

## Хранение данных

localStorage (`gorynych_dostup_v1`): объекты, замеры, обращения, настройки; фото — в IndexedDB. Версия данных `ver` (сейчас 3) повышается вместе с функцией `migrateUnits`; старые копии при загрузке переводятся автоматически (тесты в `tests/storage.test.ts`).
